# About This Site

This portfolio is inspired by **macOS Tahoe 26**, particularly its Liquid Glass design language, smooth animations, and clean, intuitive interface.

It was built using:

* [React](https://react.dev/)
* [Zustand](https://zustand.docs.pmnd.rs/)
* [UnoCSS](https://unocss.dev/)
* [TypeScript](https://www.typescriptlang.org/)
* [Vite](https://vite.dev/)

The source code is available [here](https://github.com/Nishantkumar012/portfolio).
